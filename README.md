# ZKPs-and-its-applications
This project provides a comprehensive exploration of Zero-Knowledge Proofs (ZKPs), tracing their progression from foundational theory to practical software implementation and novel application. The study begins with a theoretical analysis of ZKP principles, based on Oded Goldreich’s tutorial, to understand their core properties of completeness, soundness, and zero knowledge. It then investigates the profound claim, originating from paper "Proofs that Yield Nothing Beyond Their Validity", that ZKPs can exist for all NP problems by "reducing" formal mathematical proofs into graph 3-coloring problems.
The project then translates theory into practice by implementing an interactive ZKP system for the classic NP-complete problem of graph 3-coloring. This implementation, built in C++ as a client-server application, addresses key software challenges, including the use of cryptographic hash commitments (SHA-256), the generation of secure randomness (salts), and the management of network communication between a Prover and a Verifier using C++ Asio. The resulting software successfully demonstrates the protocol, allowing a Prover to statistically prove possession of a secret (a valid 3-coloring) without revealing it.
Finally, the project investigates the application of these foundational principles to other classic problems like Sudoku and the complex domain of electronic voting. This work explores conceptual E-voting models, analyzing how ZKPs could theoretically allow a tallying authority to prove the final result is correct without revealing individual votes, thereby highlighting the significant challenges and future potential of ZKPs in ensuring election integrity.
